# Monica 的作業倉庫

這個倉庫用來整理和存放 Monica 的各科作業。

## 目錄結構

```
Monica/
├── programming/        # 程式設計 / 資工相關作業
│   ├── python/
│   ├── java/
│   └── other/
├── general/            # 其他通用科目作業
└── assets/             # 共用資源（圖片、資料集等）
```

## 使用方式

每份作業請放在對應的科目資料夾下，並建立子資料夾，例如：

```
programming/python/hw1_calculator/
general/english/essay_week3/
```

## 說明

- 作業檔案請附上簡短說明（在各資料夾的 `README.md`）
- 程式碼作業請確認可以正常執行後再提交
- 如有參考資料請一併記錄來源
