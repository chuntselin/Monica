# 從 Droop 特性圖 → 互動式 HTML 工具：方法論

> 本文記錄如何把一張 Droop 特性圖（含公式、參數、驗證點）
> 轉換成可調參數的互動式單頁 HTML 工具。
> 以 **V-Q Droop** 為範例，下次拿到新圖直接照 § 5 步驟複製。

---

## 1. 從圖中讀取哪些資訊

拿到一張 Droop 特性圖，先找出以下元素：

| 項目 | 在圖中的位置 | V-Q 範例值 |
|------|-------------|-----------|
| 額定值 | 圖標題或公式分子 | V_LL0 = 440 V |
| Droop 比例（ratio） | 公式中用紅框標示的數字 | 0.97 |
| 最大容量 | X 軸兩端標籤 | Q_max = ±100 kVAR |
| 參考點（偏移量） | X 軸中間標籤 | Q_0 = 0 kVAR |
| 驗證點 | 圖下方文字 | Q=30 kVAR → V=436 Vrms |
| 座標軸名稱 | X/Y 軸標籤 | X: Q (VAR)、Y: V_LN (V) |

---

## 2. 核心數學關係

### 2-1. 從額定值算出操作點

```
V0   = √2 × V_LL0 / √3          ← 額定相電壓（峰值，這裡用 VLN 表示）
Vmin = V0 × ratio                ← 最低電壓（Droop 下限）
Vmax = 2×V0 − Vmin              ← 最高電壓（對 V0 對稱）
```

V-Q 範例：
```
V0   = √2 × 440 / √3 = 359.25 V
Vmin = 359.25 × 0.97 = 348.48 V
Vmax = 2×359.25 − 348.48 = 370.02 V
```

### 2-2. Droop 係數 n

```
n = (V0 − Vmin) / (Qmax − Q0)
```

V-Q 範例：
```
n = (359.25 − 348.48) / (100000 − 0) ≅ 1.08 × 10⁻⁴  (單位: V/VAR)
```

### 2-3. Droop 直線方程式

```
V_LN(Q) = V0 − n × (Q − Q0)
```

- Q 增加（送出無效電力） → V 下降
- Q 減少（吸收無效電力） → V 上升

### 2-4. 電壓單位換算

```
V_LL = V_LN × √3/√2     ← VLN 轉回線電壓
V_LN = V_LL × √2/√3     ← 線電壓轉 VLN
```

### 2-5. 驗證

代入驗證點的 Q，算出 V 確認和圖下文字吻合：
```
V_LN(30k) = 359.25 − 1.08×10⁻⁴ × (30000 − 0) = 356.01 V
V_LL      = 356.01 × √3/√2 ≅ 436 V  ✓
```

## 3. HTML 工具的模組對應

| HTML 模組 | 對應圖上的內容 |
|-----------|--------------|
| **參數輸入區**（input 欄位） | 圖中用紅框標示的可變數字（ratio、額定值、容量限制） |
| **公式顯示區** | 圖右上角的公式，帶入當前輸入值動態渲染 |
| **n 結果** | 公式下方的 `n ≅ ... ×10⁻⁴` 標示 |
| **Canvas 圖表** | 整張 Droop 特性圖（座標軸、直線、操作區域矩形、關鍵點） |
| **驗證區塊** | 圖下方的驗證點文字 |
| **資料點表格** | 量測值輸入 + 與理論值比對 |

---

## 4. Canvas 圖表畫法拆解

```
1. 計算世界座標範圍（Baseline + 目前參數 + 資料點）
2. 畫操作區域矩形  → fillRect( tx(−Qmax), ty(Vmax), ... )
3. 畫 X/Y 軸 + 箭頭
4. 畫 Droop 直線   → moveTo(−Qmax, V_LN(−Qmax))  lineTo(Qmax, V_LN(Qmax))
5. 標三個關鍵點    → (−Qmax, Vmax)、(Q0, V0)、(Qmax, Vmin)  各畫小圓點
6. 標文字標籤      → Vmax/V0/Vmin 的數值 + 對應線電壓換算
7. X 軸刻度標籤    → −Qmax、Q0、Qmax
8. 畫資料點        → 讀 dataPoints 陣列，每點畫色點（可開關標籤）
```

## 5. 拿到新圖的複製步驟

```
Step 1  讀圖
        └─ 找 X/Y 軸名稱（判斷是 V-Q / P-f / 其他）
        └─ 找額定值、Droop ratio（紅框）、容量限制、驗證點

Step 2  確認數學
        └─ 套用對應的 Droop 公式（可能不是 V-Q，需改公式）
        └─ 手算驗證點，確認和圖吻合

Step 3  改參數輸入區
        └─ 把 input 欄位改成新圖的可調變數（名稱、單位、預設值）

Step 4  改計算邏輯（compute 函式）
        └─ 依新公式改 compute()，回傳所有需要的中間值

Step 5  改公式顯示（renderFormula 函式）
        └─ 照新圖右上角公式的排版，用 HTML <span class="frac"> 重新排

Step 6  改圖表（drawGraph 函式）
        └─ X/Y 軸標籤換掉
        └─ 直線端點座標換成新的 X 軸變數
        └─ 操作區域矩形的邊界換成新的 X/Y 範圍
        └─ 關鍵點 dot() 和文字標籤換成新變數

Step 7  改驗證區塊
        └─ 換成新圖的驗證點公式

Step 8  測試
        └─ 輸入圖上的預設值，確認 n 值和圖一致
        └─ 輸入驗證點的 X 值，確認算出的 Y 值和圖下文字一致
```

## 6. V-Q 版本的預設參數

```javascript
vll0  = 440     // V_LL0，額定線電壓 (V)
ratio = 0.97    // Droop 比例（圖中紅框）
qmaxK = 100     // Q_max (kVAR)
q0K   = 0       // Q_0 參考點 (kVAR)
```

輸出：`n ≅ 1.08 × 10⁻⁴ V/VAR`
