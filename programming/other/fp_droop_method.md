# F-P Droop 特性圖 → HTML 工具：方法論

> 本文對應 `fp_droop.html`，記錄如何從 F-P Droop 圖推導出互動工具。
> 與 V-Q 版本的對照說明見最後一節。

---

## 1. 從圖中讀取的資訊

| 項目 | 在圖中的位置 | 本例數值 |
|------|-------------|---------|
| 標稱頻率 f₀ | Y 軸中心點標籤 | 60 Hz |
| 最低頻率 f_min | 公式中用紅框標示的數字 | 59.5 Hz |
| 最大有功功率 P_max | X 軸右端標籤 | 100 kW |
| 參考功率 P_ref | X 軸中心標籤 | 0 kW |
| 座標軸 | X: P (W)、Y: ω (rad/s) | — |

---

## 2. 核心數學關係

### 2-1. 從頻率算出角頻率

```
ω₀   = 2π × f₀       → 2π × 60   = 377.0 rad/s
ω_min = 2π × f_min    → 2π × 59.5 = 373.85 rad/s
ω_max = 2×ω₀ − ω_min  → 對 ω₀ 對稱 = 380.13 rad/s
f_max = 2×f₀ − f_min  → 60.5 Hz
```

### 2-2. Droop 係數 m

```
m = (ω₀ − ω_min) / (P_max − P_ref)
  = 2π × (f₀ − f_min) / (P_max − P_ref)
  = 2π × (60 − 59.5) / (100000 − 0)
  ≅ 3.14 × 10⁻⁵  (單位: rad·s⁻¹ / W)
```

### 2-3. Droop 直線方程式

```
ω(P) = ω₀ − m × (P − P_ref)
```

- P 增加（多發有功） → ω 下降（頻率降低）
- P 減少（少發有功） → ω 上升（頻率升高）

### 2-4. 單位換算

```
ω (rad/s) = 2π × f (Hz)
f (Hz)    = ω / (2π)
```

## 3. 和 V-Q 版本的對照

| 項目 | V-Q 版 | F-P 版 |
|------|--------|--------|
| Y 軸 | V_LN (V) | ω (rad/s) |
| X 軸 | Q (VAR) | P (W) |
| 係數符號 | n | m |
| 額定值 | V_LL0 (線電壓) | f₀ (頻率) |
| 可調紅框參數 | Droop ratio (Vmin/V0) | f_min (Hz) |
| 分子計算方式 | √2 × V_LL0/√3 × (1−ratio) | 2π × (f₀ − f_min) |
| 換算係數 | √3/√2 (VLN ↔ VLL) | 2π (ω ↔ Hz) |
| 資料點 Y 單位選項 | V_LN / V_LL | rad/s / Hz |

## 4. HTML 工具對應

| HTML 模組 | 對應圖中內容 |
|-----------|------------|
| 參數輸入區 | f₀、f_min（紅框）、P_max、P_ref |
| 公式顯示 | 圖右上角公式，帶入當前輸入值動態渲染 |
| m 結果 | `m ≅ 3.14 × 10⁻⁵` |
| Canvas 圖表 | ω-P 特性曲線、操作區域矩形、三個關鍵點 |
| 驗證區塊 | 代入 P=50kW 算出 ω 和 f |
| 資料點表格 | P (kW) + ω (rad/s 或 Hz)，與理論值比對 |

---

## 5. 預設參數

```javascript
f0    = 60      // 標稱頻率 (Hz)
fmin  = 59.5    // 最低頻率，圖中紅框 (Hz)
pmaxK = 100     // P_max (kW)
prefK = 0       // P_ref (kW)
```

輸出：`m ≅ 3.14 × 10⁻⁵ rad·s⁻¹/W`
